# VS Code Contract

Covers work under `extension/vscode/`.

## Mission & Scope
- Own the codebase for the VS Code extension, including command registration, sidebar trees, and webview panels.
- Maintain generated API definitions, extension-local settings, and integration scripts.
- Ensure strict security compliance (Content-Security-Policy) and robust message passing for webviews.

## Files
- `src/commands/`: Command entry points and menu registrations.
- `src/providers/`: Sidebar layouts, tree providers, and autocomplete completion suppliers.
- `src/editors/`: Custom document editors and webview panels.
- `data/`: Autocompletion data sheets and generated syntax schemas.

## Rules
- Every user-facing action, configuration setting, and activation hook must be declared in `package.json`.
- All webview panels must explicitly configure and enforce a strict `Content-Security-Policy` header.
- Never write ad hoc JSON schemas; consume api descriptors generated by `tools/docs/gen_extension_api.py`.
- Keep editor logic decoupled; delegate heavy execution tasks to the engine or background scripts rather than running them in the main extension thread.

## Workflow
- Build the bundle via `npm run build` after editing TypeScript source or webview assets.
- Verify visual panels and commands inside the VS Code Extension Development Host via local launch configurations.
- Package and lint the extension using `npx @vscode/vsce package --no-dependencies --allow-missing-repository`.
