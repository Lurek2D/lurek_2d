# Task skills

These skills are user-invoked workflows derived from the legacy prompt catalog.

Rules:
- Use them when the user explicitly asks to run a named workflow or an equivalent predefined task.
- Do not auto-load them as generic background skills.
- They may load background skills from `../skills/` as part of execution.
- Profile hints are defined in each task skill and linked to `.codex/config.toml` and `../agents/`.
