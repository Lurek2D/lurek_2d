# Newgames Catalog

This folder contains the curated playable mini-game and app set requested for the new games surface.

## Apps

- [Calculator](./calculator) - A desktop calculator with memory, history, and keyboard input.
- [CSV Table Browser](./csv_table_browser) - A CSV/dataframe viewer with schema and simple analytics.
- [Music Timeline](./music_timeline) - A piano-roll timeline composer with editable notes and playback cursor.
- [Particle Builder](./particle_builder) - A particle system editor backed by Lurek particle APIs.
