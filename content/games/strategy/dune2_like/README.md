# 🏜️ Dune2-like RTS Demo

A compact RTS-style demo with a sand-swept desert map, spice harvesting, unit selection, and enemy raids. It is intentionally lightweight and meant to feel like a classic Dune II-style skirmish prototype.

## What to do
- Select units with the left mouse button.
- Right-click to send units to a destination.
- Press T to train a trooper and B to build a refinery.
- Survive the incoming raids and keep your base alive.

## Run
```powershell
cargo run -- content/games/strategy/dune2_like
```
