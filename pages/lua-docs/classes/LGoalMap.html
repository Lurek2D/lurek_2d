Class

LGoalMap

Lua-side wrapper for a multi-source Dijkstra distance-field (goal map).

Docs home/lurek.pathfind
Class Example · Exact example · pathfind.lua
do
    local gm = lurek.pathfind.newGoalMap(16, 16)
    gm:addSource(8, 8, 1)
    gm:bake()
    print("distance_1_1 = " .. gm:distanceAt(1, 1))
end
