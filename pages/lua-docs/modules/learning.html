lurek.learning

`lurek.learning` - Lua bindings for machine learning and evolutionary computation algorithms. - Registers `lurek.learning.*` functions and types via `register()`. - Userdata types: `LuaQLearner`, `LuaNeuralNet`, `LuaGeneticAlgorithm`. - Userdata types: `LuaBandit`, `LuaNeuroevolution`, `LuaModel`. - Bridges 67 Lua-callable methods via `mlua`.

        { inputs = 3, outputs = 5, activation = "relu" },
        { inputs = 5, outputs = 2, activation = "sigmoid" }
    }
