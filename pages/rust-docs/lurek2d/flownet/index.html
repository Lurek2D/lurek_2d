Exposes the flownet subsystem module when the feature is enabled. Provides the high-level flownet module boundary for graph flow modeling, simulation, and rendering support. Connects nodes, edges, items, demand logic, routing, and update events into one runtime network surface. Delivers a complete directed-flow toolkit for gameplay systems that model transport and transformation.
