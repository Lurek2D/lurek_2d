Module pathfind 

Source
Expand description

Exposes the pathfinding subsystem module. Grid-based and graph-based pathfinding algorithms for cells, graphs, and flow fields. Collects A*, bidirectional search, JPS, HPA*, goal maps, and influence maps under one namespace. Includes grid, hex, isometric, and navmesh navigation surfaces. Keeps async dispatch and debug rendering close to the rest of the pathfinding stack.
