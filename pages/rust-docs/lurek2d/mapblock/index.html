Module mapblock

Expand description

Exposes the map block generation subsystem module. High-level mapblock module that wires blocks, scripts, constraints, and output conversion together. Exposes the procedural assembly surface used to build tilemaps from authored content. Keeps layered generation, orientation handling, and placement validation under one namespace.
