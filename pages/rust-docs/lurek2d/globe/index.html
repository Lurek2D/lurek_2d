Module globe

Expand description

Exposes the globe subsystem module. Provides the high-level globe module boundary for region topology, projection, and visual overlay orchestration. Connects rendering, fog state, markers, labels, layers, and picking into one map-runtime surface. Supports synchronization and loading flows so globe state can be updated from external game systems. Delivers a cohesive planetary-view feature set for strategic map presentation and interaction.
