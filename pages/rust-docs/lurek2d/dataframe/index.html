Exposes the dataframe subsystem module. Defines the dataframe module boundary for typed tabular storage, query execution, and serialization flows. Groups core frame models, lazy operations, SQL parsing, threaded tasks, and vectorized processing layers. Serves as the composition entry for all engine-side dataframe capabilities and integrations.
