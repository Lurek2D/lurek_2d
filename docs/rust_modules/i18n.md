## Summary

This module represents the internationalization and localization subsystem, providing tools to manage translations and regional formatting during runtime. It hosts a translation catalog that maps hierarchical locale keys from TOML, JSON, or nested Lua tables into a flattened namespace. Resilient lookup chains resolve missing text strings by walking configured fallbacks before reporting coverage gaps, facilitating language switching without restarting the game.

To deliver natural translations, the module implements dynamic placeholder interpolation and pluralization category logic. Plural selection handles grammatical rules (such as English or Slavic models) to select appropriate variations by quantity. Additionally, a regional formatting engine converts numbers and Unix timestamps into localized dates and separators, ensuring that UI components automatically display regional values.

### [catalog.rs](https://github.com/Lurek2D/lurek_2d/blob/main/src/i18n/catalog.rs)

- Provides a locale-first translation catalog that serves runtime string lookup with fallback chains.
- Stores per-locale key tables and active language state so content can switch language without rebuild.
- Performs resilient key resolution that walks configured fallback order before reporting missing entries.
- Supports import flattening from TOML and JSON trees into dot-path lookup keys for uniform access.
- Computes coverage gaps across locales to expose untranslated keys during QA and localization passes.
- Offers category grouping and search-style scans that help tools inspect large translation inventories.
- Includes locale validation, RTL detection, and system-locale discovery for startup language selection.
- Keeps lightweight caches to accelerate repeated text and word lookups in hot UI translation paths.
