# Reference Games

Reference games are larger playable projects under `lurek_2d_content/games/`. They show how several `lurek.*` modules fit together in a complete loop.

## Current Catalog

The [reference-game catalog](../lurek_2d_content/games/README.md) lists the bundled complete projects.

## Role In The Docs

Reference games are not API reference material. Use them after reading the module guides and examples when you want to see module combinations in a complete project.
