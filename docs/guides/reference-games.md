# Reference Games

Reference games are larger playable projects under `lurek_2d_content/games/`. They show how several `lurek.*` modules fit together in complete multi-file projects.

## When To Use Them

- After [Getting Started](getting-started.md) and [First Game](first-game.md).
- After browsing [Examples](examples.md) and [Module Guides](../module-guides.md).
- When you want to study project structure, content organization, and subsystem combinations in a real game instead of a one-file example.

## Current Catalog

The [reference-game catalog](https://github.com/Lurek2D/lurek_2d/blob/main/lurek_2d_content/games/README.md) lists the bundled finished games and their main APIs.

## How They Fit In The Docs

- Reference games are not the API source of truth.
- If a game uses an API in a surprising way, verify the signature in the [Full Lua API Reference](../api/lurek.md).
- If you are deciding which namespace to explore next, use [Recipes](recipes.md) or [Module Guides](../module-guides.md) first.
