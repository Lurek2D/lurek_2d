# Recipes

Recipes are short paths through the docs. They point to the canonical API and examples instead of duplicating full reference content.

## Build A Small Game

1. Read [First Game](first-game.md).
2. Use [render](../modules/render.md), [input](../modules/input.md), and [timer](../modules/timer.md).
3. Add [audio](../modules/audio.md) and [save](../modules/save.md) when the loop needs feedback and persistence.
4. Compare against [Reference Games](reference-games.md).

## Build A Simulation

1. Use [procgen](../modules/procgen.md), [physics](../modules/physics.md), [pathfind](../modules/pathfind.md), or [province](../modules/province.md) for the model.
2. Use [render](../modules/render.md), [ui](../modules/ui.md), and [charts](../modules/charts.md) for inspection.
3. Use [dataframe](../modules/dataframe.md), [compute](../modules/compute.md), and [pipeline](../modules/pipeline.md) for data-heavy flows.

## Build A Visual Tool

1. Use [ui](../modules/ui.md) for persistent controls.
2. Use [filesystem](../modules/filesystem.md), [dialog](../modules/dialog.md), and [serialize](../modules/serialize.md) for file-backed workflows.
3. Use [render](../modules/render.md), [image](../modules/image.md), and [charts](../modules/charts.md) for visual output.

## Add AI Or Automation

1. Use [ai](../modules/ai.md) for gameplay and simulation behavior systems.
2. Use [agent](../modules/agent.md) for LLM-backed runtime workflows.
3. Use [automation](../modules/automation.md) for deterministic replay, QA, and scripted demos.
