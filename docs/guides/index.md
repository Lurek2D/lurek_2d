# Guides

These guides are the user-facing entry point for building games, simulations, and desktop tools with Lurek2D.

## Recommended Path

1. Read [Getting Started](getting-started.md) for the runtime model and first run commands.
2. Build the script from [First Game](first-game.md) to learn the callback flow.
3. Use [Project Structure](project-structure.md) when your folder grows beyond one file.
4. Open [Examples](examples.md) to find runnable module-oriented scripts.
5. Use [Recipes](recipes.md) when you know the kind of project you want to build.
6. Compare against [Reference Games](reference-games.md) when you want a complete multi-file project.

## What These Guides Are Not

- They are not the generated API source of truth.
- They do not replace [Module Guides](../module-guides.md) or the [Full Lua API Reference](../api/lurek.md).
- They do not cover Rust internals or docs-generation ownership; use [Contributor Docs](../contributing/index.md) for that.
