# Lurek2D Guides

Start here when building a Lua game, simulation, visual tool, or interactive desktop app.

1. [Getting Started](getting-started.md) explains how to run a project.
2. [First Game](first-game.md) builds the smallest useful game loop.
3. [Project Structure](project-structure.md) explains scripts, assets, and configuration.
4. [Lua API Overview](lua-api.md) leads to generated signatures and callbacks.
5. [Native Procedural Graphics](procedural-graphics.md) explains retained `LShape` composition, catalogue templates, and GPU instancing.
6. [Examples](examples.md), [Recipes](recipes.md), and [Reference Games](reference-games.md) provide runnable next steps.

For exact API signatures, use the generated [Module Guides](module-guides.md) or the full [Lua API Reference](../api/lurek.md).
