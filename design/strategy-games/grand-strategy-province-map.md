# Grand Strategy Province Map

**Category:** Strategy games  
**Reference games:** Europa Universalis II, Crusader Kings II, Hearts of Iron II, Risk  
**Document type:** Technical game design and architecture

## Design target

A province-based grand strategy game focused on diplomacy, economy, war, state management, events, and long timelines. Unlike a tile 4X, the primary map is a graph of named provinces. Time can advance in daily, weekly, or monthly ticks while the player pauses to issue orders.

## Lurek2D API map

| Need | Lurek2D surface |
|---|---|
| Province topology | `lurek.province`, `lurek.pathfind` graph traversal |
| Map rendering | `lurek.render`, `lurek.svg`, `lurek.image`, `lurek.minimap` |
| Data-heavy rules | `lurek.filesystem`, `lurek.serialize`, `lurek.dataframe` |
| Countries, armies, markets | `lurek.ecs` or plain indexed domain tables |
| Events and decisions | `lurek.signal`, `lurek.dialog`, `lurek.ui` |
| AI rulers | `lurek.ai` utility scoring, blackboards, agenda phases |
| Persistence | `lurek.save` with migration-safe sections |

## Runtime architecture

Create a `WorldDate` clock that advances only when not paused. Each tick runs ordered domains: scheduled events, economy, population, diplomacy, military movement, combat resolution, AI decisions, and notification generation. Because most entities are abstract rather than spatial sprites, the province registry is the spatial authority.

Model each province with owner, controller, terrain, development, supply, unrest, buildings, local modifiers, adjacency, and screen polygon. Countries own diplomacy state, treasury, technology, armies, laws, active missions, and AI personality. Armies reference current province, destination path, arrival date, morale, manpower, and commander.

Rendering is a map-mode problem. Each map mode transforms province data into colors, stripes, icons, overlays, and tooltips. The renderer does not own strategic rules; it only consumes a prepared `MapModeView` generated by the current state.

## Vertical slice acceptance

The first slice should include a 20-province region, three countries, pause/speed controls, province selection, political and terrain map modes, one diplomatic action, army movement through adjacency, one event chain, and save/load.

## Risks

The major risk is hidden rule coupling. Grand strategy systems become unmaintainable when economy, war, diplomacy, and UI mutate each other directly. Use command/result records between domains and make every monthly tick auditable.
