# Lurek2D Tools

> [!NOTE]
> Generated by `tools/python.cmd tools/tests/gen_tool_registry.py`.

Single registry for all durable tooling under `tools/`.

## CLI Use

- Run most tools as `tools/python.cmd tools/<path>.py --help`.
- Prefer `audit/`, `validate/`, and `rag/query.py` for repeatable review flows.
- Treat `fix/`, `demos/`, and some `dev/` scripts as targeted maintenance, not default MCP tools.
- MCP registration should prefer entries marked `candidate`: stable input, bounded output, and low-surprise side effects.
